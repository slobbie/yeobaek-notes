# 공개 블로그 분석 기준

## 목적

분석 이벤트는 여백의 노트에서 어떤 콘텐츠와 탐색 기능이 실제로 사용되는지 확인하기 위한 근거다. 방문자를 식별하거나 개인별 행동을 추적하지 않는다. 브라우저 이벤트는 Supabase Edge Function에서 다시 검증하고, 데이터베이스 기록 함수가 동일한 허용 계약과 공개 글 메타데이터를 확인한 뒤 저장한다.

## 이벤트 계약

모든 이벤트에는 `name`, `occurred_at`, `page_path`, `properties`가 있다. `page_path`에는 쿼리 문자열과 해시를 포함하지 않는다.

| 이벤트 | 발생 시점 | 허용 속성 | 확인할 지표 |
| --- | --- | --- | --- |
| `page_viewed` | 공개 경로가 표시될 때 | 없음 | 전체·글별 조회 이벤트 수 |
| `post_opened` | 글 목록에서 제목을 눌렀을 때 | `post_slug`, `category` | 목록에서 글로 이동한 비율 |
| `search_used` | 검색을 마치고 입력창을 벗어날 때 | `query_length`, `results_count` | 검색 사용 수, 결과가 있는 검색 비율 |
| `filter_applied` | 주제를 선택할 때 | `value` | 주제별 탐색 사용 수 |
| `archive_expanded` | `글 더 보기`를 눌렀을 때 | `visible_count`, `total_count` | 목록을 더 펼쳐 본 횟수와 도달한 글 수 |
| `source_opened` | 글의 외부 출처를 열 때 | `post_slug`, `source_host` | 글 조회 대비 출처 확인 비율 |

사용자 수나 전환율로 표현하지 않는다. 식별자와 세션이 없으므로 현재 계산값은 이벤트 횟수를 기준으로 한 탐색 비율이다.

## 수집하지 않는 값

- 이름, 이메일, 로그인 정보, IP 주소, 기기 식별자
- 사용자·세션 식별자와 광고 식별자
- 검색어 원문과 본문 자유 입력값
- URL의 쿼리 문자열·해시와 전체 외부 출처 주소
- 브라우저 지문을 만들 수 있는 속성 조합

검색은 글자 수와 결과 수만 남긴다. 외부 출처는 경로와 쿼리를 버리고 hostname만 남긴다.

## 수집 경계

- 공개 브라우저는 `analytics_events`와 집계 테이블에 직접 접근하지 않는다.
- `collect-analytics` Edge Function은 요청 크기, 허용 Origin, 이벤트 이름, 속성, 경로와 시각을 검증한다.
- DB `record_analytics_event` 함수는 최대 24시간 이내 이벤트만 받고, 글·분야·출처 속성이 현재 발행 콘텐츠와 일치하는지 확인한다.
- 관리자는 로컬 서버의 `service_role`로 일 집계만 읽는다. 원본 이벤트를 관리자 화면에 노출하지 않는다.

## SEO·GEO 지표와의 관계

블로그 내부 이벤트만으로 검색 노출이나 AI 인용 성과를 주장하지 않는다. 배포 후 Search Console의 노출·클릭·클릭률·색인 상태와 내부 글 조회를 기간·글 단위로 함께 비교한다. 생성형 검색의 노출이나 인용은 확인 가능한 원본 데이터가 생겼을 때만 별도 지표로 보고한다.

## 보존 방침

원본 이벤트는 최대 90일, 개인 식별값이 없는 일·글 단위 집계는 최대 24개월 보존한다. `prune_analytics_data` DB 함수를 Supabase Cron이 매일 실행하여 기간을 넘긴 행을 삭제한다.

## 관리자 지표 정의

| 지표 | 분자 | 분모 | 한계 |
| --- | --- | --- | --- |
| 페이지 조회 | `page_viewed` 횟수 | 없음 | 사용자·세션 수가 아니다. |
| 글 열기 | `post_opened` 횟수 | 없음 | 목록의 글 제목 클릭만 세며 외부 진입은 포함하지 않는다. |
| 결과 있는 검색 | `results_count > 0`인 `search_used` 횟수 | 전체 `search_used` 횟수 | 검색어 의도나 개인 전환을 알 수 없다. |
| 출처 확인 | `source_opened` 횟수 | 없음 | 전체 URL이 아닌 hostname별 횟수다. |
| 주제·목록 탐색 | `filter_applied`, `archive_expanded` 횟수 | 없음 | 반복 동작을 각각 세며 개인별 비율을 계산하지 않는다. |

## 개발 환경 확인

개발 서버에서 브라우저 개발자 도구의 콘솔을 열면 `[여백의 노트 분석]`으로 시작하는 이벤트를 확인할 수 있다. 이 출력은 개발 환경에만 존재하며 공개 화면에는 별도 관찰 화면을 추가하지 않는다.
